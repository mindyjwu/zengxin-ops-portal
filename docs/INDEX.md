# Project index — start here

One folder, one source of truth. Point any Claude surface (chat, Cowork, Code) at this file first.

| Where | What goes here |
|---|---|
| `/CLAUDE.md` | Project context + conventions (auto-read by Claude Code) |
| `/docs/INDEX.md` | This map |
| `/docs/DECISIONS.md` | Decision log + open questions (dated, one line each) |
| `/docs/links.md` | Every useful link: Drive docs, vendor pages, subsidy programs, meeting invites |
| `/docs/deliverables/` | Exported Word/PDF files (cost analysis, meeting prep, estimation prompts) — name as `YYYY-MM-DD_topic_lang.docx` |
| `/docs/ltc-portal-walkthrough.md` | 15-minute stakeholder walkthrough |
| `/TEST_PLAN.md` | Test plan |

## Rules of thumb
1. If it was decided, it is in `DECISIONS.md` with a date. If it is not there, it is not decided.
2. Chat output worth keeping gets exported into `docs/deliverables/` the same day.
3. Anything containing real client financials or personal data belongs only in a **private** repo/folder — see the visibility note in `DECISIONS.md`.
